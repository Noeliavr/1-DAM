Ejercicio 4

Dadas las cuentas:

create table cuentas (
    id_cuenta int primary key,
    titular varchar(100),
    saldo decimal(10,2)
);

insert into cuentas values
(1, 'Ana', 100),
(2, 'Luis', 100);


Mostrar un ejemplo de deadlock entre dos sesiones.


Sesión 1

start transaction;

select saldo
from cuentas
where id_cuenta = 1
for update;

Sesión 2

start transaction;

select saldo
from cuentas
where id_cuenta = 2
for update;
