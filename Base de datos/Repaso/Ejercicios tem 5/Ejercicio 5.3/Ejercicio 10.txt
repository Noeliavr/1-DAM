Ejercicio 10


Mostrar qué ocurre cuando una sesión bloquea una fila y otra intenta bloquear la misma fila.


start transaction;

select *
from cuentas
where id_cuenta = 1
for update;




start transaction;

select *
from cuentas
where id_cuenta = 1
for update;



update cuentas
set saldo = saldo - 10
where id_cuenta = 1;

commit;


select *
from cuentas
where id_cuenta = 1;

commit;
